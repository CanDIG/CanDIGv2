Navigate the sidebar to view API docs for all CanDIGv2 services.

Each endpoint should have a snippet that gives a guide for how you might use the endpoint with a curl command.

You will need to replace `https://your-candig-domain` with the domain of your CanDIG node.

<Aside type="tip">The examples are not comprehensive and you will likely have to add an auth header to each command with `-H 'Authorization: Bearer '$TOKEN`.</Aside>

<Aside type="note">These docs are automatically generated from the respective OpenAPI schemas.</Aside>
